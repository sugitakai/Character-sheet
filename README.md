# Character-sheet

## 概要
何のために作ったWebアプリなのか
ゴブリンスレイヤーtrpgというテーブルゲームをもっと多くの人が親しみやすい形にするため、作成キット的なツールを作りました
ゴブリンスレイヤーtrpgを初心者が始めるにあたって一番取り掛かりづらく遊ぶために必要不可欠な作業である自分のキャラクターを作成する工程を簡単かつクリエイティブで楽しめるものに変えるために生み出しました。

## デモ
Herokuなどの公開URL

## 使用技術
- PHP
- Laravel
- Vue.js
- TypeScript
- Vite
- MySQL / SQLite

## 主な機能
- キャラクター作成
- 能力値の自動計算
- 種族・生まれによる能力補正
- ダイスロール
- 武器・防具・盾データ
- キャラクター情報管理

## 工夫した点
- Vueコンポーネントへの分割
- TypeScriptによる計算ロジックの分離
- Service / Rule / Dataへの責務分離
- DBによるマスターデータ管理
