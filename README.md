# Character-sheet

## 概要
テーブルトークRPG「ゴブリンスレイヤーTRPG」のキャラクター作成を支援するWebアプリです。

ゴブリンスレイヤーTRPGを始める際、初心者にとって取り組みづらい工程の一つである「キャラクター作成」を、より簡単かつクリエイティブに楽しめるようにすることを目的として制作しています。

キャラクターの能力値計算や種族・生まれによる補正、ダイスロールなど、キャラクター作成に必要となる処理をWeb上で行えるようにしています。

現在も機能追加・設計改善を行っています。

## デモ
Herokuなどの公開URL

## 使用技術
- PHP
- Laravel
- Vue.js
- TypeScript
- Vite
- MySQL / SQLite

## 主な機能
- キャラクター作成
- 能力値の自動計算
- 種族・生まれによる能力補正
- ダイスロール
- 武器・防具・盾データ
- キャラクター情報管理
